# Master Tiger de Taekwondo — site institucional

Landing page da Academia Master Tiger, de Cachoeirinha-RS. A academia mantém há cerca de 30 anos um projeto social que oferece aulas gratuitas de taekwondo para crianças, jovens e adultos.

O site foi feito como atividade extensionista do Cesuca (2023), envolvendo as disciplinas de Projeto e Desenvolvimento de Aplicações para Web e de Interação Humano-Computador.

## Objetivo

Dar à academia uma presença profissional na internet e facilitar o contato de possíveis patrocinadores com o projeto.

## O que tem no site

- Apresentação da academia e galeria de fotos
- Instrutores
- Depoimentos de alunos e familiares (carrossel)
- Competições, aulas e infraestrutura
- Formulário de contato com envio de e-mail (EmailJS)
- Mapa, horários e redes sociais
- Layout responsivo para celular, tablet e desktop

## Tecnologias

- HTML, CSS (organizado no padrão ITCSS) e JavaScript
- EmailJS para o formulário
- Design prototipado no Figma
